# Technical Documentation

This folder documents the structure and behavior of CaesarCipherScript. The diagrams use [Mermaid](https://mermaid.js.org/) syntax so they can be viewed and maintained directly in the repository.

## Contents

- [Architecture](architecture.md): main application components and their relationships.
- [User workflow](user-workflow.md): interaction sequence for encrypting or decrypting a message.
- [Input validation flow](validation-flow.md): handling of invalid menu options and keys.
- [Cipher algorithm](algorithm.md): character-by-character Caesar cipher process.

## Scope

The diagrams describe the current command-line implementation. The application is an educational implementation of the Caesar cipher and is not intended to provide modern cryptographic security.
